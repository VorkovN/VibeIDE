# VibeIDE

Локальная IDE на Qt Widgets и C++23 для macOS. Она объединяет Git-историю, diff коммитов, терминалы и настройки запуска проектов C++ и Python.

## Сборка на macOS

Понадобятся Xcode Command Line Tools, Homebrew и Git. Установите зависимости и запустите из корня исходников следующую последовательность.

```sh
brew install cmake pkgconf qtbase libvterm
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH="$(brew --prefix qtbase)"
cmake --build build --parallel
open build/VibeIDE.app
```

Собранный этим способом `VibeIDE.app` использует Qt и libvterm из Homebrew. На машине коллеги выполните те же команды сборки. Для запуска проектов нужны их собственные компиляторы, интерпретаторы и инструменты сборки.

## Работа с проектами

- Откройте **Settings → Theme…** в верхней строке меню macOS или нажмите **⌘,**. Выбор светлой или тёмной темы сохраняется между запусками.

- Нажмите **+** в строке **C++**, **Python** или **Web** слева и выберите папку. Проект откроется во вкладке этой группы.
- Перетаскивайте вкладки проектов в верхней панели. Порядок вкладок каждой группы сохраняется между запусками.
- Во вкладке **Current Changes** показаны только файлы с незакоммиченными изменениями и новые файлы, которые Git ещё не отслеживает. По клику вкладка **Changes** сравнивает версию выбранного файла из **HEAD** с содержимым рабочей папки.
- Во вкладке **Commits** история обновляется автоматически при изменениях в локальном репозитории. Новые коммиты показаны сверху, а старые подгружаются при прокрутке вниз. Цветные линии показывают ветвления и слияния. **Fetch** загружает коммиты и ссылки из удалённого репозитория, **Add** добавляет выбранные файлы в индекс, **Commit** записывает изменения из индекса с указанным сообщением.
- Левый или правый клик по коммиту открывает меню **Cherry-pick**, **Checkout**, **View Changes**. Просмотр открывается в закрываемой вкладке **Changes** справа от **Files**. Выберите файл и режим **Side by Side** или **Unified**. **F7** и **Shift+F7** переходят между изменениями в файле.
- Shift-клик по коммиту выделяет диапазон для **Squash**. Можно объединить последовательные коммиты без слияний от текущего HEAD на локальной ветке с чистой рабочей копией.
- Во вкладке **Files** можно раскрывать папки проекта и просматривать текстовые файлы.
- **+** в панели **Terminal** создаёт оболочку в корне проекта. При закрытии VibeIDE сохраняет количество вкладок и текущий каталог каждой оболочки. При открытии вкладки запускается новая оболочка в сохранённом каталоге. Если каталога больше нет, приложение использует корень проекта.
- В группе Python **Configurations → New Configuration…** создаёт конфигурацию для скрипта или модуля. Можно указать интерпретатор, аргументы, рабочий каталог, переменные окружения и запуск через `uv` в существующем окружении.
- В группе Web **Configurations → New Configuration…** позволяет указать исполняемый скрипт. Кнопка **Run** запускает его из корня проекта.
- После первого запуска конфигурация появляется в **Recent Configurations**. Вкладка **Run** закрепляется слева от терминалов и подсвечивает уровни логов. Пока выбранная конфигурация работает, кнопка **Run** становится **Stop**. Для запуска C++-проектов используйте терминал.

Состояние проектов и конфигураций сохраняется локально между запусками VibeIDE. Конфигурации запуска восстанавливаются, если закрыть вкладку проекта и снова открыть ту же папку в той же группе. История вывода терминалов хранится в памяти в пределах 1 500 строк на вкладку.
